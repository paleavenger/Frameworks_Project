# TeamProject Manager

## Назначение

TeamProject Manager — учебная консольная программа для управления проектными командами студентов. Она помогает собрать команду, назначить участникам роли и быстро оценить готовность команды к началу работы.

## Целевая аудитория

Студенты, преподаватели и кураторы учебных проектных команд.

## Предметная область

Организация совместной работы над учебными проектами: распределение студентов по командам, назначение ролей и контроль минимального состава команды.

## Основные сущности

- **Студент** — имя и направление подготовки участника.
- **Команда** — название и список студентов.
- **Проект** — тема, над которой работает команда.
- **Роль** — функция студента в проекте: аналитик, разработчик, дизайнер или тестировщик.

## Реализованные функции

1. Добавление студента в команду с проверкой повторного добавления.
2. Назначение студенту роли с проверкой наличия участника в команде.
3. Расчёт готовности команды по количеству участников и назначенных ролей.

## План дальнейшего развития

- добавить интерактивное меню и сохранение данных в JSON;
- реализовать редактирование и удаление студентов;
- добавить несколько проектов и перенос участников между командами;
- подключить базу данных и веб-интерфейс;
- реализовать авторизацию студентов и преподавателей.

## Запуск

```text
python main.py
```

Для запуска в PyCharm нужно выбрать интерпретатор `Python 3.13 (PR1_Frameworks)` из каталога `.venv` и запустить файл `main.py`.
