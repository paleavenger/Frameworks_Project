# Практическая работа №1 — TeamProject Manager

Это первоначальная версия проекта до разбиения на модули и добавления
JSON-хранилища.

## Что реализовано

- добавление студента в команду;
- назначение роли студенту;
- расчёт готовности команды;
- использование переменных, строк, чисел, условий, преобразования типов
  и импорта модуля `datetime`.

## Запуск

Из корня проекта:

```text
python pr1_version/main.py
```

Или открыть папку `pr1_version` в PyCharm отдельно и запустить `main.py`.
